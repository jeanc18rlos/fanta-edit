# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue.

Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. If that is not available to you, email support@fantaisa.net.

Include the Fanta version and build, your macOS version, the steps to reproduce, and the impact you observed. Remove secrets and private project content from any logs you attach.

## What to expect

- Acknowledgement of your report within a few days.
- A fix or mitigation plan once the issue is confirmed, and credit in the advisory if you want it.
- Coordinated disclosure: please give us a reasonable window to ship a fix before publishing details.

## Supported versions

Fanta is in Public Alpha. Only the latest published build receives security fixes.

## Scope

In scope: the Fanta app, its project and `.fig` import parsers, the local MCP bridge, the headless engine and API, and the update and signing pipeline. Vulnerabilities in third-party dependencies are best reported upstream; tell us too if Fanta is exposed.
