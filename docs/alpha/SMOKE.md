# Fanta alpha smoke test

Run on the build machine and again on a second macOS account, downloading the
DMG through a browser so quarantine is exercised the way a tester will hit it.

Start from a clean profile:

```
rm -rf ~/Library/Application\ Support/Fanta ~/Library/Logs/Fanta
```

[`REHEARSAL.md`](REHEARSAL.md) records the original dry run of this checklist;
[`RELEASE_VALIDATION.md`](RELEASE_VALIDATION.md) records the later focused
native and automated checks. Row 0 passed **18 of 18, exit 0** against a release
build on 2026-09-09. Subsequent native fixtures exercised Scale, Path Select,
generation workspaces, recovery across restarts, and other bounded flows, but
this entire pointer-driven checklist has not yet passed against one release
artifact. Do not promote a focused fixture result into a claim that its whole
row passed.

The current source-only Text on Path, preview-persistence, and canvas-context
slice passes all 706 viewer tests; 116 text unit tests and one doctest, with one
network test ignored; 21 renderer TextPath tests; five document TextPath tests;
297 tools tests (290 unit, six end-to-end, and one ink oracle); and 596 GPUI
checks (593 unit and three architecture), with one doctest ignored. Its focused
Agent request-framing, attachment, external-context, queue, mention, and URI
checks also pass, as does package-scoped `./script/clippy` for `fanta-text`,
`fanta-render`, `fanta-doc`, `fanta-tools`, `fanta-gpui`, `fig_viewer`,
`acp_thread`, `agent`, and `agent_ui`. This is automated source evidence only:
the combined flow below has not passed in a native build or release artifact.

Rows marked **new** were added after the rehearsal — from its wave-2 list, and
from the Gatekeeper dance it never exercised because it ran an unbundled debug
binary. Nobody has run any of them.

| 6 | Click every visible toolbar tool and command. Exercise Scale and Path Select. Select one simple visible/unlocked vector with no paint or one normal solid fill/stroke, invoke **Text on Path**, edit its text, exercise mixed-direction text and a ligature, and Undo/Redo. Exercise the API-debug start preview, including commit, cancel, and changing selection mid-preview. With nodes selected first on a page and then in a component master, click the Agent attachment control; inspect and remove each resource, try rapid attachments, and repeat with nothing selected. Submit a prompt through **Ask AI**. Open each media-AI workspace. Run Export from Actions. | Move/drawing tools act; Scale and Path Select visibly transform/edit a selection. Text on Path replaces the eligible vector in place, immediately enters curved inline editing, preserves identity/placement, renders and exports, and Undo/Redo restores the vector/text-path states. The inspector permits the documented font family, Regular/Italic style, weight, size, line height, pixel letter spacing, start/center/end alignment, underline/strikethrough, side/orientation, and API-debug start segment/position edits. Its synthetic glyph Fill permits RGB and opacity only; structural paint actions are unavailable. During an active content preview, autosave/direct persistence and relevant external reconciliation wait; commit produces one undo step, while cancel or selection change restores and refreshes before persistence resumes. Visual bidirectional navigation follows display order. Caret positions within one multi-grapheme shaping cluster may be equal subdivisions rather than exact glyph-internal positions; missing source-cluster geometry fails closed rather than inventing a caret interval. Unsupported rounded, clipped, degenerate, hidden/locked, gradient/image/blended, or multiply-painted vectors show a specific notice without mutation. Text-path direction has no typed UI, and color/bitmap glyphs skip path-only inner-shadow/background-blur effects. Each attachment is a named, reviewable, removable immutable JSON snapshot scoped to the active page or component root, with exact ids, an omitted count, stable document/path/project/root/scope identity, bounded descriptive strings, at most 64 included nodes, and at most 128 KiB. Its identity matches `design_state`; mixed-root/off-root selections are rejected, rapid requests retain order, and nothing sends automatically. With no selection the existing Agent Add Context menu opens. Dev mode/tools and voice still raise *"&lt;control&gt; is not available in the Fanta alpha yet."* — never a silent click. Ask AI opens an unsent Agent draft with page/selection context. Image, Video, Vector and Masks commands open their matching workspace. Group/Ungroup/Frame and the four text-AI commands are registered and automatically verified. Export writes the default preset to `<project>/exports/`, preserves sidebar state, and shows running plus success or failure feedback on the canvas. **Remaining limitations:** the automated candidate source gate passes, while this combined native save/reopen/export/attachment-removal flow is pending; Voice and Dev mode are unfinished; preset/format configuration is still hidden with the legacy inspector section. Verify this entire flow natively against the final artifact. |
